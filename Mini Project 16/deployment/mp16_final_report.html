Catatan kejujuran ilmiah

  • Dataset MP9 = rekaman suara asli 4 anggota kelompok (96 WAV); split per acquisition block sehingga setiap penutur ada di train, validation, dan test. Test berisi penutur yang sudah dikenal model (sesi berbeda), jadi akurasi bukan estimasi untuk penutur baru.
  • Test set (16 sampel) dibuka sekali di MP13; interval kepercayaan masih lebar (Wilson 95% akurasi [0.72, 0.99]).
  • Ucapan non-keyword untuk uji penolakan adalah TTS (kelompok tidak merekam kata non-keyword), sehingga laju penolakan belum mewakili suara manusia.
  • Latency/RAM perangkat (ESP32/RPi) belum diukur; sketch ESP32 disediakan sebagai baseline porting.
